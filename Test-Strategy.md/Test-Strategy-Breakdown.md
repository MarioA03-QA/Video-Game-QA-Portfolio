# Game QA Test Strategy

## Testing Objectives
What I am trying to determine through testing.

## Scope
What is being tested.

## Testing Approach
Exploratory testing
Functional testing
Regression testing

## Priority Assessment
The amount of priority which should be given to the issue.

## Severity Assessment
The level of severity the issue possesses.

## Test Environment
Platform, game version, date encountered, location of bug etc.

## Steps to Reproduce
The inital steps taken that led to the discovery of the issue and how it could be potentially recreated.

## Expected & Actual Results
An evaluation of how the product is supposed to behave in contrast to how it actually behaves.

## Regression Strategy
How fixes will be verified and how I would ensure the already existing functionality hasn't been affected.

## Documentation
Test cases
Bug reports
Test results
Regression results

## Conclusion
Brief summary of the final results after further QA testing has been conducted
