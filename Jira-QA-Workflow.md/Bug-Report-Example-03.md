# Jira Bug Report Example

## Overview

This is an example of a bug report created in Jira during my Game QA testing.
The report demonstrates how I document an issue so that another member of a development team can understand the problem, reproduce it and investigate a potential fix.
Below the screenshots, I have included the information explored in the bug reports.
